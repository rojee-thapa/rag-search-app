# RAG Search App

This is a **RAG (Retrieval-Augmented Generation) Search Application** built with **Next.js**, **Supabase**, and **OpenAI**.  

It allows users to upload documents and perform AI-powered semantic searches over them.

## Features

- Upload and manage documents
- Search using AI-powered embeddings
- Interactive PDF viewer
- Modern UI with React components

## Tech Stack

- **Next.js** – Frontend framework
- **Supabase** – Database and file storage
- **OpenAI API** – Natural language search

## Getting Started

Follow these steps to run the project locally:

1. **Clone the repository:**  
   ```bash
   git clone https://github.com/rojee-thapa/rag-search-app.git

2. **Install dependencies:**  
   ```bash
   npm install

- The first line is normal text (`2. **Install dependencies:**`).  
- The command `npm install` goes inside a **code block** (between triple backticks).  
- The `bash` after the first three backticks is optional but makes the code block highlighted properly on GitHub.  

---

3. **Run the development server:**  
   ```bash
   npm run dev

4. **Open in browser:**  
   Go to [http://localhost:3000](http://localhost:3000)
